# 출처, 변환 범위와 라이선스 고지

이 Codex 하네스 스킬은 두 원본 저장소의 설계 패턴을 고정 commit에서 조사하고, 기존 Codex 포트를 비교 자료로 사용해 Codex 네이티브 계약으로 재구현한 파생 작업이다. 원본 파일의 단순 경로 치환이나 100개 하네스의 일괄 복제가 아니다.

## 변환·재구현한 내용

### `revfactory/harness`에서 변환한 설계

- 원본의 Markdown 중심 메타 설계 절차를 Codex 사용자 스킬 구조인 `.agents/skills/<name>/`에 맞게 재구성했다.
- 원본의 런타임 전용 경로·팀/메시지/작업 API와 고정 모델 지시를 Codex 네이티브 역할·스킬·subagent 계약으로 바꿨다.
- 서술형 역할과 단계 설명을 role, task, dependency, artifact, write-set, review policy, failure policy를 가진 JSON 명세 계약으로 재구현했다.
- 생성과 정적 검사를 Python 표준 라이브러리 기반 스캐폴더와 validator로 분리했다.
- 생성 전 dry-run, 대상 루트 검사, 심볼릭 링크 탈출 거부와 기본 무덮어쓰기를 추가했다.
- 원본의 품질 평가 개념을 should-trigger, near-miss, 정상·기존·오류 fixture, with-skill 기준선과 구조 assertion으로 구체화했다.

### `revfactory/harness-100`에서 추출한 패턴

- 입력 정규화, artifact 기반 DAG, 부분 실행, 독립 reviewer, 교차 산출물 일관성, 제한된 수정 루프를 교차 도메인 규칙으로 추출했다.
- 원문 1,808개를 사용자 스킬로 설치하지 않고, 고정 commit에서 만든 검색 가능한 축약 카탈로그와 인덱스로 사용한다.
- 한국어판을 구조 참고의 우선 원천으로 삼되, 고정 역할 수, 특정 기술 스택과 도메인 사실은 복제하지 않았다.
- 고위험 도메인의 최신 주장과 품질 향상 수치는 제품 보장으로 재사용하지 않았다. 필요한 사실은 실행 시점의 1차 출처로 다시 확인하도록 했다.

### 기존 Codex 포트에서 참고한 내용

`SaehwanPark/meta-harness`의 고정 commit은 선행 구현 비교점이다. Codex에서 어떤 개념을 보존하거나 바꿔야 하는지 확인하는 데 사용했으며, 해당 포트를 이 패키지의 실행 원본이나 업데이트 채널로 취급하지 않는다.

이 구현은 공식 사용자 스킬 경로, optional `agents/openai.yaml`, 프로젝트 custom agent와 `AGENTS.md`의 조건부 사용, 기계 검증 가능한 JSON 명세를 자체 계약으로 정의했다. 기존 포트와 같은 이름이나 목적이 보이더라도 현재 파일의 동작은 이 패키지의 설계와 테스트가 기준이다.

## Apache-2.0 수정 고지

원본 `revfactory/harness`와 `revfactory/harness-100`은 모두 Apache License 2.0으로 제공된다. 이 패키지는 라이선스 전문 하나를 `assets/licenses/Apache-2.0.txt`에 변경 없이 보존하고, 두 원본의 저작권 고지, 저장소, 고정 SHA와 이 파생 작업의 수정 고지를 `assets/NOTICE`에 함께 보존한다. 배포·재패키징할 때는 라이선스 전문과 `NOTICE`를 모두 포함해야 한다.

원본 라이선스 파일의 SHA-256은 다음과 같다.

```text
bae1caa988a742c5a756faa45e33b6c72f21f9873b8e7f1e0ce87fcf0a4c747b
```

수정 고지: 2026-08-01에 원본 자료를 Codex 네이티브 스킬로 사용하기 위해 문서 구조, 경로, 실행 모델, 명세 형식, 검증 절차, 안전 경계와 테스트 기준을 변경하고 재구현했다. 변경된 파일은 원본과 동일한 동작이나 인터페이스를 보장하지 않는다.

Apache-2.0 제4조에 따라 파생 자료를 재배포할 때는 라이선스 사본, 관련 저작권·특허·상표·귀속 고지와 수정 고지를 유지해야 한다. 이 패키지에서는 `Copyright 2025 robin`과 `Copyright 2026 Robin`을 포함한 `assets/NOTICE`가 그 보존 대상이다. 원본 또는 다른 의존 자료의 추가 `NOTICE`를 사용하는 경우에도 관련 귀속을 해당 라이선스 조건에 따라 보존해야 한다.

## 상표와 비보증

저장소명, 프로젝트명, 회사명과 제품명은 출처 식별을 위해서만 사용한다. Apache-2.0은 출처를 합리적으로 설명하거나 `NOTICE`를 재현하는 경우를 제외하고 licensor의 상호, 상표, 서비스표 또는 제품명 사용 권한을 부여하지 않는다.

이 포트는 `revfactory`, `harness`, `harness-100`, `SaehwanPark/meta-harness`, Anthropic, Claude, OpenAI 또는 Codex의 승인, 제휴, 인증이나 보증을 주장하지 않는다. 각 원본과 기여물은 해당 라이선스가 정한 범위에서 보증 없이 제공되며, 이 문서도 법률 자문을 대신하지 않는다.

## 재현성과 업데이트

- 출처를 갱신할 때는 branch 이름이 아니라 새 전체 commit SHA를 기록한다.
- 카탈로그나 규칙을 다시 추출하면 이전 SHA, 새 SHA, 변경된 패턴과 회귀 결과를 함께 남긴다.
- 원본 라이선스가 바뀌지 않았는지 전문과 SHA-256을 다시 확인한다.
- 현재 패키지의 provenance를 수정하지 않고 출처 파일만 교체하지 않는다.
- 새 원본이나 포트를 참고하면 사용 범위와 복제하지 않은 범위를 이 문서에 추가한다.

이 provenance는 기능 설명이 아니라 재사용과 검증의 경계를 기록한다. 구현의 실제 동작은 현재 패키지의 명세, 스크립트와 검증 결과로 확인해야 한다.

이 프로젝트의 수정 고지(2026-10-31): 위 내용은 구축에 사용한 로컬 harness 스킬의 출처 기록을 보존한 것이다. 이식한 프로젝트 스킬의 정적 검사에서 다른 런타임 지시로 오인되지 않도록 원문의 비지원 API/경로/모델 토큰 열거만 일반 설명으로 바꿨다. Game Trend Report용 명세·운영 계약·준비 검사기는 저장소에 별도로 작성했다. 라이선스와 저작권 고지는 assets/Apache-2.0.txt와 assets/NOTICE에 보존했다.
