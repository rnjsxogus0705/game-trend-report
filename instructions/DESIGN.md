# 디자인 계약 진입점

시각 설계의 단일 기준은 저장소 루트 [DESIGN.md](../DESIGN.md)다. 이 안내만 읽고 설계를 완료한 것으로 처리하지 말고 루트 문서의 맥락·토큰·컴포넌트·상태·검수 조건을 실제로 읽는다. 기존 위치는 예약 작업과 이전 참조의 경로 호환성을 위해 유지하며 값은 복제하지 않는다.

Impeccable은 루트 DESIGN.md와 PRODUCT.md를 사용한다. 주간 제작 하네스의 새 context.json에는 이 안내와 루트 DESIGN.md 각각의 실제 SHA256을 기록한다. UI 증거는 루트 문서의 현재 해시와 결속하며 내용·한국어·공개 출처 조건은 다른 instructions 계약도 함께 따른다.
