# 리포트 지침 편집과 동기화

이 폴더와 `../workflows/`가 제작 지침·실행 흐름의 원본입니다. 다른 컴퓨터나 GitHub 웹 편집기에서 수정하고 main에 커밋·푸시하면 로컬 예약 작업이 최신 커밋을 받아 적용합니다.

- REPORT-GUIDE.md: 조사·편집·콘텐츠 구성
- REPORT-OUTPUT-CONTRACT.md: 고정 섹션·근거·출력·검수 조건
- KOREAN-EDITORIAL-POLICY.md: 한국어 3단계 교정
- DESIGN.md: Toss 스타일·Pretendard·시각 규칙
- CONTENT-AUDIT-2026-10-31.md: 초기 검토 기록(현재 규칙보다 우선하지 않음)
- WORKFLOW.md: 조사부터 배포·전송·지침 동기화까지
- sync-manifest.json: 공개 파일과 로컬 적용 위치 대응표

현재 본문 순서는 TOP 10 → GitHub 트렌딩 → 게임 AI 도구 → AI 중심 게임 제작 특집 → 게임 분석 → 아이디어 3개 → 한국어 자료입니다. 과거 문구와 충돌하면 각 지침 마지막의 최신 추가 규칙을 우선합니다.

공개 저장소에는 비밀키, DPAPI 파일, 전송 기록, 개인 조사 원장, 예약 앱 내부 파일을 넣지 않습니다. 원격 코드·지침은 저장소 쓰기 권한이 있는 사람이 변경할 수 있으므로 main에 반영할 내용을 검토하세요.
